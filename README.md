# ЭХО — По ту сторону тишины

Атмосферный платформер: мир исчезает во тьме, а звуковые волны на мгновение раскрывают его контуры. Игра для компьютера и телефона. Восемь комнат с постепенным открытием, 24 обрывка истории, 16 достижений, маяки возвращения и автоматическое сохранение.

## Быстрый запуск

Распакуй архив в отдельную папку и открой **index.html** в браузере на ПК. Все файлы должны оставаться рядом в исходной структуре. Ничего устанавливать и собирать не нужно.

На телефоне удобнее открывать игру по ссылке после публикации. Играть можно в обеих ориентациях; горизонтальная даёт больше места для управления.
